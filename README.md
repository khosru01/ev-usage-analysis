# ev-usage-analysis
Analysis of Electric Vehicle usage trends based on regional and brand-wise data.

📊 Electric Vehicle Usage Analysis
This project presents an analysis of electric vehicle (EV) usage patterns across different regions and brands, using real-world data. The dataset explores key metrics such as consumer preferences, discount patterns, and brand popularity, offering insights into the global EV market landscape.

🔍 What's Included:
An Excel dataset with cleaned and structured data on EV usage.

Key findings highlighting brand-wise and region-wise trends.

Actionable insights for understanding consumer behavior in the EV market.
## Key Findings

- **Nissan** offered the highest discount, while **Tesla** provided the lowest.  
- The **Oceania** region has the highest usage of electric vehicles (EVs), whereas **Europe** ranks the lowest.  
- **Kia** is the most popular brand, with the highest number of consumers.  
- Although **BMW** ranks second, the difference in the number of users between BMW and Kia is minimal.  
- **Tesla** has the lowest number of consumers among the brands analyzed.
